# Identity Service

A microservice responsible for user management, authentication, and authorization within the EduFlow platform.

## 🛠 Features

* User registration and authentication.
* User profile management.
* JWT (JSON Web Token) based authentication.
* Role-based access control (RBAC).
* Management of roles and permissions.
* Integration with Eureka Service Discovery.

## 🏗 Technology Stack

* **Framework**: Spring Boot 3.2.x
* **Security**: Spring Security 6.x
* **Database**: PostgreSQL
* **Database Migration**: Flyway
* **Service Discovery**: Eureka Client

## ⚙️ Configuration

The following environment variables (or equivalent properties in `application.yml`) are required:

* **POSTGRES_HOST**: PostgreSQL database host.
* **POSTGRES_USER**: Database username.
* **POSTGRES_PASSWORD**: Database password.
* **JWT_SECRET**: Secret key used to sign and validate JWT tokens.
* **JWT_EXPIRATION**: Token expiration time in milliseconds.

## 📡 API Endpoints

### Authentication

* `POST /api/v1/auth/register` — Register a new user account.
* `POST /api/v1/auth/login` — Authenticate a user and obtain an access token.
* `POST /api/v1/auth/validate` — Validate a JWT token.

### Users

* `GET /api/v1/users/me` — Retrieve information about the currently authenticated user.
* `GET /api/v1/users/{id}` — Retrieve user information by ID (internal use).
* `PUT /api/v1/users/{id}` — Update user profile information.

## 🔐 Authorization Roles

The service supports the following predefined roles:

| Role         | Description                                   |
| ------------ | --------------------------------------------- |
| `USER`       | Standard learner account                      |
| `INSTRUCTOR` | Course creator and instructor                 |
| `ADMIN`      | System administrator with elevated privileges |

## 🔍 Health Check

Endpoint:

```text
http://localhost:8081/actuator/health
```

This endpoint can be used to verify the health and availability of the Identity Service.

## 📝 Notes

* JWT tokens generated by this service are validated by the API Gateway.
* The value of `JWT_SECRET` must be identical across services that need to validate JWT tokens.
* Flyway automatically applies database migrations during application startup.
* User and role information can be accessed internally by other services through secured APIs or service-to-service communication.
